# HG 设计规范与动效清单

## 视觉定位与核心气质

以现代清透片库（参考红果短剧找片结构、Fladder 与 Infuse 的原生克制秩序）融合沉浸式双模观影体验为核心：

- **克制、现代化、干净**：优先通过字号、字重、间距与细分隔线建立层级，严禁卡片套卡片、炫彩渐变与冗余徽章堆砌。
- **默认自动跟随系统浅/暗双色**：发现、追剧、离线与设置界面严格遵循系统外观（浅色通透微暖纸白，暗色深邃中性炭黑），并允许在设置中手动覆写。
- **观影舞台统一沉浸暗底**：无论系统处于浅色还是暗色，进入播放页后主视频舞台固定采用影院语义暗色令牌（`cinema-bg` / `cinema-surface` / `cinema-fg`），确保视频画面成为唯一视觉焦点。

## 语义 Tokens

所有界面颜色、圆角与动效参数均来自 [theme.json](./theme.json) 与 `src/ui/token.rs`，业务切片与页面层严禁直接书写原始色值或绕过 `src/ui/` 使用底层未样式化控件。

| 语义角色 | 浅色基准 | 暗色基准 | 用途 |
| :--- | :--- | :--- | :--- |

| `sidebar` / `sidebar-border` | `#F3F4F6` / `#E5E7EB` | `#16181D` / `#262932` | 桌面左侧导航壳与分隔线 |
| `card` / `border` | `#FFFFFF` / `#E6E8EC` | `#1A1C22` / `#2A2D36` | 内容卡片与轻描边 |

## 平台与导航规范

- **桌面端（macOS / Windows）**：隐藏系统标题栏，应用自绘主题融合标题栏（保留原生窗口控制按钮留白与拖拽区）；左侧固定侧栏承载 3 个主业务入口（`发现`、`追剧`、`离线`），`设置` 独立收口在侧栏最底部隔离区；播放页默认进入**电影模式**并内置 PotPlayer 风格快捷键（`Space` 播停、`Enter` 全屏、`1`/`2`/`3`/`4` 画面比例、`←/→` 快退快进、`↑/↓` 音量或短剧切集、`M` 静音、`Z/X/C` 倍速、`Esc` 退出/关闭）。
- **移动端（Android）**：底部 3 Tab 承载 `发现`、`追剧`、`离线`（触控热区 >= 48dp），`设置` 收口在顶栏右上角独立图标入口；播放页默认进入**短剧模式**（竖屏沉浸 + 右侧轻浮层 + 半屏选集/评论抽屉）。

## 动效令牌（`src/ui/token.rs`）

| 令牌 | 时长 | 曲线 / 行为 | 适用场景 |
| :--- | :--- | :--- | :--- |
| `INSTANT` | `120ms` | ease-out | 悬停浅染、边框与文字颜色过渡 |
| `FAST` | `180ms` | soft settle，按下缩放 `0.97`（图标 `0.95`） | 按钮按压反馈、胶囊切换 |
| `BASE` | `240ms` | ease-in-out | 导航选中态、分段指示条滑动、播放/暂停图标切换 |
| `SLOW` | `320ms` | ease-out | 浮层抽屉展开、短剧/电影模式布局切换、卡片微幅入场 |
| `STAGGER_STEP` | `40ms`（上限 8 项） | ease-out | 发现页首屏剧目网格轻波浪入场 |

所有动效统一遵守 `reduce_motion()`：开启减弱动态效果时，缩放、位移与波浪入场立即归零并直接呈现终态。

## 屏幕动效清单（Motion Inventory）

### 1. 应用导航壳（`app/shell.rs`）

| 状态变更 | 工具与令牌 | 减弱动态效果 |
| :--- | :--- | :--- |
| 侧栏 / 底栏导航项悬停 | `transition_colors` + `INSTANT`（120ms），背景淡入 `accent` | 即时切换 |
| 导航项按压 | `transition_transform` + `FAST`（180ms），按压缩放 `0.97` | 保持 `scale 1.0` |
| 主导航选中项切换 | `transition_colors` + `BASE`（240ms）平滑高亮当前项与底部隔离设置入口 | 即时切换 |
| 桌面侧栏折叠 / 展开 | `LayoutAnimation` + `BASE`（240ms） | 即时跳变 |

### 2. 发现首页（`pages/discover.rs`）

| 状态变更 | 工具与令牌 | 减弱动态效果 |
| :--- | :--- | :--- |
| 顶部推荐横幅与剧目网格初次入场 | `motion().entering(FadeInUp)` + `SLOW`（320ms）+ `STAGGER_STEP`（40ms，最多 8 张） | 无位移即时显示 |
| 分类胶囊 / 快捷筛选切换 | `nsh_base::tabs` 原生滑动 `indicator_style` + `BASE`（240ms） | 即时切换 |
| 剧目海报卡片悬停与按压 | 悬停 `transition_colors`（`INSTANT`），按压 `transition_transform` 缩至 `0.97`（`FAST`） | 无缩放，保留边框强调 |
| 快捷「继续观看」横条操作按钮 | `AppButton` 统一悬停浅染（`INSTANT`）与按压反馈（`FAST`） | 无缩放 |
| 空态 / 错误态切换 | 静态明确提示与重试按钮（无无意义装饰循环动画） | 保持一致 |

### 3. 双模式播放页（`pages/player.rs`）

| 状态变更 | 工具与令牌 | 减弱动态效果 |
| :--- | :--- | :--- |
| 进入播放页（从发现页直进） | 导航栈原生推入过渡，暗色舞台平滑呈现 | 即时切换 |
| 短剧模式 <-> 电影模式切换 | 舞台与伴随栏切换采用 `motion().entering(FadeIn)` + `BASE`（240ms） | 即时切换 |
| 播放 <-> 暂停按钮与状态反馈 | `AppButton` 按压缩放 `0.95`（`FAST`）+ 图标与文案状态同步过渡（`BASE`） | 即时切换 |
| 选集网格选中当前集 / 切集 | 选中胶囊边框与底色 `transition_colors`（`FAST`），伴随播放进度重置 | 即时切换 |
| 画面比例档位（`1`/`2`/`3`/`4`）与倍速切换 | 选中态胶囊 `transition_colors`（`FAST`）+ 右上角短促状态提示淡入淡出（`BASE`） | 即时切换 |
| 伴随栏 Tab（简介 / 选集 / 评论）切换 | `nsh_base::tabs` 滑动指示条（`BASE`） | 即时切换 |
| 实时播放秒数跳动 | **无动画**（高频每秒更新，使用 `tabular-nums` 等宽数字防止抖动） | 保持一致 |
