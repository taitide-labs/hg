# HG 设计规范与动效清单

## 视觉定位与核心气质

以现代清透片库（红果短剧找片心智 + B 站 Web 与移动端观影交互秩序 + Fladder / Infuse 的克制原生留白）为核心：

- **克制、现代化、干净**：优先通过字号、字重、间距与细分隔线建立层级，严禁卡片套卡片、炫彩渐变、工程状态标签与冗余徽章堆砌。
- **全局浅/暗主题连续一致**：发现、共用搜索/列表页、追剧、离线、设置与常规播放页全部遵循当前系统或用户外观（默认跟随系统自动切换浅色/暗色）。点击进入播放页**不强制切暗色**，仅视频画面框本身保持自然黑底；仅在真全屏或竖屏 9:16 沉浸铺满时由视频占满视口。

## 平台、导航与页面结构规范

- **3+1 导航壳**：
  - 桌面端（macOS / Windows）：隐藏系统标题栏，应用自绘主题融合标题栏；左侧固定侧栏承载 `发现`、`追剧`、`离线` 3 个主入口，`设置` 通过细分隔线独立收口在侧栏最底部。进入播放页真全屏时隐藏标题栏、侧栏与右侧信息流，视口 100% 仅保留视频画面与画内自动隐藏控件。
  - 移动端（Android）：底部 3 Tab 承载 `发现`、`追剧`、`离线`（触控热区 >= 48dp），`设置` 收口在顶栏右上角独立图标入口。
- **发现首页与共用二级列表页**：
  - 发现首页取消首屏巨型焦点横幅与行内标签堆砌。顶部放搜索输入框，下方按统一楼层结构依次展示 `精选推荐`、`排行榜` 与各分类推荐楼层；每个楼层右侧统一提供 `全部 >` 入口。
  - 搜索、精选全部、排行榜全部与分类全部**共用同一个二级列表页**，集中承接关键词搜索、分组标签筛选、排序与三榜切换。
- **播放页（对齐 B 站 Web 与移动端交互）**：
  - **画内控播放**：不出现“正在播放第几集”“电影模式/短剧模式”文字、比例徽章或视频下方播控按钮。画内底栏由上至下为全宽细进度条 + 控制行（左侧 `播停` + 时间；右侧 `倍速`、`音量`、`⚙` 设置、`横竖屏沉浸` 纯图标、`全屏` 纯图标）。右下角 `⚙` 向上弹出轻菜单（`自动连播`、`单集循环`、桌面端 `外部播放器打开`）。
  - **画面比例与快捷键**：界面不展示比例按钮，默认按视频源比例智能适配；桌面端保留 PotPlayer 快捷键（`Space` 播停、`Enter` 真全屏、`1`/`2`/`3`/`4` 切换画面比例并闪现轻提示、`←/→` 快退快进、`↑/↓` 音量或竖屏切集、`M` 静音、`Z/X/C` 倍速、`Esc` 退出全屏或返回）。
  - **桌面端右侧单列信息流**：左侧视频下方仅留 `追剧` 与 `离线下载` 两个轻操作按钮；右侧为一条自然衔接的可滚动信息流：顶部剧名与折叠简介（`展开` / `收起`）→ 选集区（默认按当前集数前后折叠，点 `展开` / `收起` 查看完整分段网格）→ 常规只读评论流（含浅灰底嵌套回复预览）。
  - **移动端**：常规横屏视频采用上半屏视频 + 下半屏 `简介 | 评论` 双 Tab；9:16 竖屏短剧或点击画内竖屏图标时全屏铺满播放，上下滑切集，边缘浮现极简操作图标。

## 动效令牌（`src/ui/token.rs`）

| 令牌 | 时长 | 曲线 / 行为 | 适用场景 |
| :--- | :--- | :--- | :--- |
| `INSTANT` | `120ms` | ease-out | 悬停浅染、边框与文字颜色过渡 |
| `FAST` | `180ms` | soft settle，按下缩放 `0.97`（图标 `0.95`） | 按钮按压反馈、胶囊切换、设置菜单开关 |
| `BASE` | `240ms` | ease-in-out | 导航选中态、分段指示条滑动、简介与选集展开收起 |
| `SLOW` | `320ms` | ease-out | 浮层面板弹出、竖屏沉浸切换、海报轻波浪入场 |
| `STAGGER_STEP` | `40ms`（上限 8 项） | ease-out | 发现页首屏剧目卡片轻波浪入场 |

所有动效统一遵守 `reduce_motion()`：开启减弱动态效果时，缩放、位移与波浪入场立即归零并直接呈现终态。

## 屏幕动效清单（Motion Inventory）

### 1. 应用导航壳（`app/shell.rs`）

| 状态变更 | 工具与令牌 | 减弱动态效果 |
| :--- | :--- | :--- |
| 侧栏 / 底栏导航项悬停 | `transition_colors` + `INSTANT`（120ms），背景淡入 `accent` | 即时切换 |
| 导航项按压 | `transition_transform` + `FAST`（180ms），按压缩放 `0.97` | 保持 `scale 1.0` |
| 主导航选中项切换 | `transition_colors` + `BASE`（240ms）平滑高亮当前项与底部隔离设置入口 | 即时切换 |
| 真全屏隐藏 / 恢复标题栏与侧栏 | 状态切换即时释放视口空间，确保视频无抖动铺满 | 保持一致 |

### 2. 发现首页与共用列表页（`pages/discover.rs`）

| 状态变更 | 工具与令牌 | 减弱动态效果 |
| :--- | :--- | :--- |
| 精选推荐、排行榜与分类楼层海报入场 | `motion().entering(FadeInUp)` + `SLOW`（320ms）+ `STAGGER_STEP`（40ms，最多 8 张） | 无位移即时显示 |
| 搜索框聚焦与楼层 `全部 >` 跳转 | 进入共用列表页采用轻淡入过渡（`BASE`） | 即时切换 |
| 列表页分组标签 / 榜单 / 排序切换 | `nsh_base::tabs` 原生滑动 `indicator_style` + `BASE`（240ms） | 即时切换 |
| 剧目海报卡片悬停与按压 | 悬停 `transition_colors`（`INSTANT`），按压 `transition_transform` 缩至 `0.97`（`FAST`） | 无缩放，保留边框强调 |
| 空态 / 错误态切换 | 静态明确提示与重试按钮（无装饰性循环动画） | 保持一致 |

### 3. 播放页（`pages/player.rs`）

| 状态变更 | 工具与令牌 | 减弱动态效果 |
| :--- | :--- | :--- |
| 进入播放页 | 保持当前浅/暗主题无闪烁切入，画布淡入（`BASE`） | 即时切换 |
| 常规视图 <-> 竖屏沉浸切换 | 画面容器切换采用 `motion().entering(FadeIn)` + `BASE`（240ms） | 即时切换 |
| 画内右下角 `⚙` 设置 / 倍速浮层弹出 | `motion().entering(FadeIn)` + `FAST`（180ms）向上展开 | 即时显示 |
| 简介与选集 `展开` / `收起` | 内容区块平滑切换（`BASE`），当前选集高亮 `transition_colors`（`FAST`） | 即时切换 |
| 快捷键比例切换（`1`/`2`/`3`/`4`）提示 | 画内轻提示浮层淡入（`FAST`） | 即时显示 |
| 实时播放秒数与进度条更新 | **无动画**（高频更新，使用 `tabular-nums` 等宽数字防止抖动） | 保持一致 |
