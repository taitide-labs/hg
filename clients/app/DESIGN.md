# HG 客户端设计规范

## 视觉原则

以清透、克制的原生片库体验为基准，优先通过字号、字重、间距与细分隔线建立信息层级，避免卡片嵌套卡片、装饰性渐变与工程状态噪音。

- **默认深色沉浸一致性**：发现、搜索、追剧、历史、离线、设置与常规播放页均默认采用深色影院外观（可在设置中切换为浅色或跟随系统），画报卡片直接融合主画布底色、无外框盒边并采用紧凑 `12px` 间距，进入常规播放页保持视频画布深色容器与右侧信息流视觉一致；仅在真全屏或 9:16 竖屏沉浸态由视频占满视口。
- **统一设计原语**：所有颜色、圆角、字号与动效参数来自 [theme.json](./theme.json) 与 `src/ui/token.rs`；业务切片与页面层统一复用 `src/ui/` 组件，不直接书写原始色值、裸 `nsh_base` 控件、副作用或命令式定时器。

## 导航壳与响应式布局

应用采用 **5+1** 主导航结构：5 个主入口为 `发现`、`搜索`、`追剧`、`历史`、`离线`，`设置` 通过细分隔线独立置于导航底部。

- **桌面端（macOS / Windows）**：
  - 隐藏系统标题栏，使用应用自绘主题融合标题栏；标题栏左侧提供侧栏折叠按钮（播放页态切换为 `返回`）。
  - 侧栏支持拖动右边缘调节宽度（`180px–320px`）与手动收起为 `60px` 图标轨，偏好持久化至本地存储。
  - 当窗口宽度小于 `760px` 时自动折叠为图标轨，保留主内容区可读空间且不覆盖用户持久化偏好；窗口拉宽后自动恢复。
  - 进入播放页真全屏时隐藏标题栏、侧栏与右侧信息流，视口完整交付视频画布。
- **移动端（Android）**：
  - 不使用底部常驻 Tab 栏；采用顶部轻标题栏（左汉堡菜单 + 居中标题 + 右侧搜索快捷入口），点击菜单唤出左侧抽屉承载全部 5+1 导航项。
  - 统一响应系统返回手势：优先关闭弹层/抽屉，再退出二级页或播放页。

## 页面与交互规范

### 发现与列表页

- **发现首页**：不设首屏焦点横幅与内嵌搜索框，按统一楼层依次展示 `最近更新`、`排行榜` 与各频道分类推荐，楼层右侧提供 `全部 >` 入口。
- **视口自适应楼层**：根据实际内容宽度动态计算海报列数（`minmax(156px, 1fr)`）与榜单列数（`minmax(220px, 1fr)`），并预补足候选剧目数量，确保全屏与宽屏下展示更多剧目且首行无残缺尾项。
- **二级列表页**：承接 `最近更新全部`、`排行榜全部` 与 `分类全部`，支持排序/三榜切换与触底无限滚动加载（无手动“加载更多”按钮），通过请求序号隔离过期响应。

### 搜索页

- **搜索输入栏**：输入框内有内容时在右侧显示清空图标（`×`），点击清空关键词并重置搜索结果；关键词直接交由上游检索。
- **搜索历史与热搜**：展示历史检索词条与热搜词，支持单条移除与清空全部历史（清空前需二次确认）。
- **分组题材标签**：自动过滤无标签的空分组；单个分组超过单行宽度时默认收起为单行并在行尾显示 `+` 展开按钮，点击切换展开/收起（`-`）。选中标签后展示 `最热` / `最新` 排序与无限滚动结果。

### 播放页

- **画内播控底栏**：
  - 底部悬浮透明遮罩承载全宽进度条（`4px` 轨道、`12px` 滑块）与单行控制栏；左侧为播放/暂停图标与等宽时间读数（`12px`），右侧为 `倍速` 按钮（`12px` 与时间字号一致）、`静音`、`播放设置`、`竖屏视图`、`全屏`（均为 `16px` 图标配 `28×28` 点击热区）。
  - 播放态无操作 3 秒后自动隐藏；悬停、暂停、展开浮层或拖动进度条期间保持可见。
  - 拖动或点击进度条跳转时锁定目标位置并忽略短暂回传的旧播放进度，防止播放中拖动闪烁回弹。
  - 双击视频画面区域切换播放/暂停并唤出播控栏；桌面端支持常用快捷键（`Space`、`Enter`、`Esc`、`←/→`、`↑/↓`、`M`、`Z/X/C`、`1/2/3/4`）。
- **桌面右侧单列信息流**：
  - 视频下方仅保留 `追剧` 与 `离线下载` 两个操作按钮。
  - 右侧信息流依次展示：剧名、评分/集数元数据与**完整展开的剧目简介及标签** → 选集区（默认展示当前集邻近窗口，支持展开查看 50 集分段网格）→ 只读分集评论流（触底无限滚动，支持楼中楼回复抽屉）。
- **移动端**：常规横屏采用上半屏视频 + 下半屏 `简介 | 评论` 双 Tab；点击竖屏图标进入全屏沉浸播放。

### 离线页与破坏性操作确认

- **单页统一视图**：上方为 `下载中` 队列区，下方为 `已下载` 托管离线片库。队列中存在排队、解析或下载中任务时，页面按固定间隔自动轮询刷新进度与归档状态；无运行中任务或离开页面时自动停止轮询。
- **已下载分集弹窗**：点击剧目卡片的 `分集` 入口弹出侧滑抽屉（移动端为底部表单），展示剧目总集数与已下载集数、50 集分段切换及全集网格；已下载分集以品牌高亮色区分于灰显未下载分集。默认模式点击已下载分集直接离线起播，切换 `删除分集` 模式后点击单集触发确认删除。
- **二次确认**：清空观看历史、移除单条观看记录、清空搜索历史、删除离线剧目与删除单集离线缓存均通过系统原生确认弹窗（`AlertDialog`）二次确认后执行。

## 动效令牌与清单

动效令牌统一定义于 `src/ui/token.rs`，并遵守 `reduce_motion()`（开启减弱动态效果时取消位移与缩放，直接呈现终态）：

| 令牌 | 时长 | 曲线 / 行为 | 适用场景 |
| :--- | :--- | :--- | :--- |
| `INSTANT` | `120ms` | ease-out | 悬停浅染、边框与文字颜色过渡 |
| `FAST` | `180ms` | soft settle，按压缩放 `0.97` | 按钮按压、胶囊切换、浮层与弹窗响应 |
| `BASE` | `240ms` | ease-in-out | 导航选中态、分段指示条、侧滑抽屉入场 |
| `SLOW` | `320ms` | ease-out | 竖屏沉浸切换与首屏海报波浪入场 |
| `STAGGER_STEP` | `40ms`（上限 8 项） | ease-out | 发现页剧目卡片轻波浪入场 |

- 实时播放秒数、进度条拖拽与下载进度刷新不做补间动画，统一使用 `tabular-nums` 等宽数字避免宽度抖动。
