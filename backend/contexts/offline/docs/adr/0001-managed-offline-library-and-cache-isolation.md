# 托管离线片库并与播放缓存物理隔离

Status: accepted

在线播放缓冲与用户显式发起的离线下载在生命周期、存储归属和淘汰语义上完全不同。决定将离线下载建设为应用内托管的持久化离线片库，采用单集单份择优存储与临时区原子提交机制，并与在线播放缓存、目录缓存彻底物理隔离。

## 备选方案

- 面向外部文件系统的纯文件导出工具（直接输出 MP4 到用户目录）：割裂了应用内在线与离线无缝连播体验，且难以统一维护断网元数据和续播状态。
- 与在线播放缓存复用同一存储池：缓存自动淘汰或用户一键清理缓存时会误删显式下载的离线分集。

## 影响

- 清空播放缓存或目录缓存绝不会影响离线片库中的任何内容。
- 下载入队时必须同步固化剧目元数据与解密后本地封面快照，确保完全断网可浏览离线片库。
- 删除正在播放的离线分集时，须通过事件通知观影追剧上下文先行停止播放并释放文件句柄，避免 Windows 等平台的文件占用删除失败。
