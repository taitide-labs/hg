# 片库目录

本上下文属于支撑域并承接上游内容适配通用能力，负责封装上游短剧免登录只读源的边缘加密通道、封面解密、错误归一化与目录缓存，提供首页聚合、推荐与上新、一级分类、分组标签、排行榜、全文搜索、剧目详情及分集只读评论浏览，并向上下游核心域提供单集在线播放凭据。

## 术语

**剧目**：一部包含基本信息、标签与分集目录的短剧或漫剧作品。

- 等价：`Series`
- 避免：视频、Video、短剧详情

**分集**：隶属于某部剧目、按序号排列的单集视频条目。

- 等价：`Episode`
- 避免：剧集、章节、Ep

**频道分类**：上游站点用于划分内容大类的一级内容分类，如短剧、漫剧。

- 等价：`Category`
- 避免：排序频道、栏目

**题材标签**：按题材或受众维度分组的剧目属性标识。

- 等价：`Tag`
- 避免：分类、关键词

**榜单**：按热门、潜力或推荐维度排序的剧目排行集合。

- 等价：`Ranking`
- 避免：专题、合集

**分集评论**：依附于特定剧目分集的只读用户评论及其楼中楼回复。

- 等价：`EpisodeComment`
- 避免：弹幕、动态

**播放凭据**：用于从上游视频源拉取单集流媒体所需的有时效签名流地址集合与鉴权信息。

- 等价：`PlaybackTicket`
- 避免：播放链接、离线分集

**目录缓存**：系统自动保留、受容量淘汰且可手动清空的上游元数据与已解密封面临时副本。

- 等价：`CatalogCache`
- 避免：离线下载、离线片库
